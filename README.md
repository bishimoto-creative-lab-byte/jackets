# jackets

菱礎グループ 創造室(Bishimoto Creative Lab)のジャケット画像置き場です。
SUZURIの「ジャケ写シリーズ」に登録した曲の画像を、元のサイズ(3000×3000 PNG)で保管しています。

- ホームページ用リポジトリ(bishimoto-creative-lab-site)には画像を置かず、ジャケット画像はここにまとめる
- ファイル名は曲名をローマ字・英小文字にし、単語をハイフンでつなぐ
- SUZURIは登録時に画像をコピーするため、ここで画像を消しても商品には影響しない
